# Sprint 3 Review

**Sprint Goal:** スプリントの振り返りを残せ、完了点数の履歴と簡易バーンダウンが見える

**期間メモ:** Sprint 2（DnD / ポイント）の上にレトロ・終了履歴・バーンダウンを追加

## 完了したストーリー

| # | ストーリー | 状態 |
|---|------------|------|
| 1 | レトロメモ（開始 / 途中 / 終了）をスプリントに保存（localStorage） | Done |
| 2 | スプリント終了 → Done 点数を履歴へ。ベロシティ（件数・平均）表示 | Done |
| 3 | 残ポイントの簡易バーンダウン（SVG、ステータス/ポイント変更でスナップショット） | Done |
| 4 | `docs/SPRINT3.md` / README 更新、`npm run build` 通過 | Done |

## デモ手順

```bash
npm install
npm run dev
```

1. 「データ初期化」で Sprint 3 サンプルを載せる
2. **レトロメモ**（開始時 / 途中 / 終了時）を編集 → リロードしても残ること
3. カードを Done へ移す / ポイントを変える → **バーンダウン**の実線が下がる（または残が変わる）こと
4. 「スプリントを終了」→ **ベロシティ**に完了 pt が1件追加され、平均が表示されること
5. 新しいゴールで「スプリントを開始」→ 新しいバーンダウンが始まること
6. 履歴の「レトロメモ」を開いて、終了済みスプリントのメモが見えること

## 技術メモ

- 状態: `AppState.history: SprintRecord[]`、`Sprint.burndown` / `retroStart|During|End` / `committedPoints`
- 残ポイント = Todo + Doing の合計。列移動・ポイント変更・削除時に値が変わればスナップショット追加
- バーンダウン: 依存なしの SVG（理想線は点線）
- 既存キー `ai-scrum-lab:v1` を拡張（`history` 欠落時は `[]` に正規化）
