**Sprint Goal:** カードを列間でドラッグでき、各カードにポイントを付けられる（＋簡単なポイント合計）

**期間メモ:** Sprint 1 ボード上に DnD / ポイント編集 / 合計を追加

## 完了したストーリー

| # | ストーリー | 状態 |
|---|------------|------|
| 1 | 各カードのストーリーポイントをインライン編集（localStorage 永続化） | Done |
| 2 | `@dnd-kit` による Todo / Doing / Done（＋バックログ）間ドラッグ＆ドロップ | Done |
| 3 | 既存の移動ボタンを維持（アクセシビリティ・フォールバック） | Done |

## デモ手順

```bash
npm install
npm run dev
```

1. 「データ初期化」でサンプルを載せる（初回起動でもシードされる）
2. カード右上の数値入力でポイントを変更 → リロードしても残ること
3. カード左の **⋮⋮** をドラッグして Todo ↔ Doing ↔ 完了、またバックログ ↔ Todo へ落とす
4. ヘッダー／列ヘッダーの **pt** 合計が増減すること
5. ボタン（→ Doing など）でも従来どおり移動できること

## 技術メモ

- DnD: `@dnd-kit/core`（PointerSensor、列を droppable、カードを draggable）
- ポイント変更は `App.setItemPoints` → 既存 `saveState`（`ai-scrum-lab:v1`）
- スプリント開始フローは変更なし
